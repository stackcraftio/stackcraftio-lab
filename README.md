### Publish on GitHub Pages

1. Open your existing repository **stackcraftio/stackcraftio-lab**.
2. Upload **index.html**, **style.css**, **script.js**, **README.md**, and the entire **assets/** folder to the repository root. (Use **Add file → Upload files** and keep the folder structure.)
3. Commit the changes to `main`.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**; choose **main** and **/(root)**, then click **Save**.
5. After GitHub finishes deploying, open **https://stackcraftio.github.io/stackcraftio-lab/**. GitHub Pages hosts the site continuously; you do not need to leave your computer running. Deployments may take a few minutes.
6. Add the live link to your GitHub profile README and the repository's **About → Website** field.

### Edit projects

Change titles, descriptions, status labels or repo URLs in `script.js`. All cards are actual HTML elements. A planned project intentionally displays **COMING SOON ♡** rather than a fake link. Add a URL once that repository is created. To change artwork, replace the corresponding individual image in `assets/`.

> The page is real HTML/CSS/JavaScript. The banner and project illustrations are cropped from the reference artwork you provided; the artwork itself is not editable as text. Everything else is editable code.
